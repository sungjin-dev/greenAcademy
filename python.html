Step 4. 논리적인 흐름 제어

2. 반복문 (For)

목록에 있는 데이터를 하나씩 꺼내어 반복합니다.

tasks = ["대시보드 UI 기획", "데이터베이스 연동", "사용자 테스트 진행"] print("=== 오늘 할 일 목록 ===") for task in tasks: print(task)
파이썬의 생명: 들여쓰기(Indentation)
`if`나 `for` 다음 줄은 반드시 Tab 키를 눌러 들여써야 합니다. 들여쓰기가 틀리면 프로그램이 동작하지 않습니다.

Step 4. 제어문 및 함수(`def`) 정의

1. 조건문 & 반복문

students = [{"name": "철수", "score": 85}, {"name": "영희", "score": 55}] for s in students: if s["score"] >= 60: result = "합격" else: result = "재시험" print(f"{s['name']}: {result}")

2. 함수 재사용

def calculate_stats(score_list): total = sum(score_list) avg = total / len(score_list) return total, avg total, avg = calculate_stats([90, 80, 100]) print(f"총점: {total}, 평균: {avg:.1f}")
핵심: 들여쓰기(Indentation) — 파이썬은 Tab 들여쓰기가 규칙입니다.

Step 5. Streamlit 웹 서비스 제작 기술

화면 출력 기능

  • st.title(): 가장 큰 메인 제목
  • st.info(): 파란색 알림 박스 출력
  • st.success(): 초록색 성공 메시지
  • st.columns(): 화면 가로 분할 레이아웃

데이터 입력 & 상태 관리

  • st.text_input(): 텍스트 입력 칸
  • st.button(): 클릭 이벤트 발생
  • st.form(): 여러 입력을 한 번에 전송
  • st.session_state: 새로고침 후에도 로그인 상태 유지

Step 6. Firebase 클라우드 DB 연동

Firebase 인프라 설정

  • 1. Firebase Console ➔ 새 프로젝트 생성
  • 2. Firestore Database 활성화 (테스트 모드)
  • 3. 서버 위치: asia-northeast3 (서울)
  • 4. 비공개 키 JSON 발급 ➔ key.json 저장

파이썬 연동 코드

import firebase_admin from firebase_admin import credentials, firestore cred = credentials.Certificate("key.json") if not firebase_admin._apps: firebase_admin.initialize_app(cred) db = firestore.client()

※ key.json은 app.py와 같은 경로에 있어야 합니다.

import streamlit as st st.title("📊 학생 성적 관리 웹앱") if "students" not in st.session_state: st.session_state.students = [] # 입력 폼 with st.form("student_form"): col1, col2 = st.columns(2) with col1: name = st.text_input("학생 이름") with col2: score = st.number_input("점수", min_value=0, max_value=100, value=80) if st.form_submit_button("학생 추가") and name: st.session_state.students.append({"이름": name, "점수": score}) st.success(f"{name} 학생 등록 완료!") # 결과 대시보드 if st.session_state.students: col_l, col_r = st.columns(2) with col_l: st.table(st.session_state.students) with col_r: avg = sum([s["점수"] for s in st.session_state.students]) / len(st.session_state.students) st.metric("총 학생 수", f"{len(st.session_state.students)}명") st.metric("평균 점수", f"{avg:.1f}점")
